# Cornerstone Unbound

**Classic modded Minecraft, refined for today.**

Cornerstone Unbound is an open-ended Minecraft modpack built around influential mods from the 1.12.2 era, paired with carefully selected fixes, performance improvements, compatibility work, thoughtful configuration, and modern quality-of-life features.

The goal is to preserve the character of classic modded Minecraft while smoothing out rough edges that make older packs harder to return to today.

## Issues and Requests

Use [GitHub Issues](https://github.com/zachsem/Cornerstone-Unbound/issues) for actionable reports and requests.

- **Bug Report** — crashes, broken behavior, compatibility problems, or reproducible pack issues.
- **Feature / Mod Request** — mod suggestions, configuration changes, quality-of-life ideas, or other pack requests.

For bugs, include enough information to reproduce the problem and attach a log or crash report when relevant.

## Scope

Cornerstone Unbound is intended to remain a broad, open-ended experience rather than an expert or tightly scripted progression pack.

Configuration changes focus on compatibility, reducing unnecessary overlap, performance, stability, and making the overall experience more cohesive without unnecessarily changing the identity of the included mods.
